# One Emoji, One Smile

Exactly one emoji, and nothing else, chosen to make a stranger smile. `main.ts` (Node 22, stdlib only, no network) writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), checks it is a single emoji within the 1–8 character gate with no surrounding white space, reads it back and verifies the bytes match.

> "🫶"

Heart hands: two hands forming a heart — a stranger's warmest gesture, kind and gently playful, universal across ages and backgrounds, clearly picked for the moment rather than the first smiley that comes to mind, and platonic, so it reads right coming from someone unknown.
