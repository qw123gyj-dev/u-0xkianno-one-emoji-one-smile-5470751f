# One Emoji, One Smile

One emoji and nothing else, picked to make a stranger smile. `main.ts` (Node 22, stdlib only, no network) writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), checks it against the gate — 1 to 8 characters, not only white space, exactly one pictographic emoji with nothing around it — then reads the file back and compares the bytes.

> "🫶"

Heart hands: two hands shaping a heart — a gesture of sending warmth, readable in a glance with no words and no context. It is not a default smiley face, so it reads as chosen for the moment; it needs no language and no in-joke, so it lands the same way for any age or background; and it is platonic gratitude, not intimacy, flirtation or sarcasm, so it reads right coming from someone unknown.
